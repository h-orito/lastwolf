## 背景・現状

- 現状、迷惑行為や規約違反ユーザーに対しユーザーが運営に報告する公式手段が無い
- 運営が問題ユーザーを把握する仕組みも無いため、対応が後手になる
- ブロック機能（#8）は私的な制限であり、運営側の対応とは別軸で必要
- 既存の「**突然死回数による自動入村制限**」は実態に合っていない / 誤検知が多いため、本 Issue で **撤去** し、運営が通報を見て判断する手動制限に置き換える

## 対応方針

### ユーザー側
- 任意のユーザー / 発言 に対して「通報」できる UI を追加（理由テキスト + カテゴリ選択）
  - カテゴリ案: 「暴言」「ネタバレ・荒らし」「規約違反」「その他」（要確認）
- 同じ対象への重複通報は 1 ユーザーにつき 1 件まで（または期間内）に制限

### 集計・通知
- 同一対象（ユーザー or 発言）への通報件数が **閾値（要確認、例: 3 件）** を超えたら管理者に通知
  - 通知手段: 通報一覧ページの未対応バッジ表示が最小。メール / Slack 連携は後続検討
- 通報自体は閾値前から記録（あとから一覧で見える）

### 管理者向け
- **管理者のみが閲覧できる通報一覧ページ** を追加（ルーティング + 認可ガード）
- 一覧の項目: 通報日時 / 通報者 / 被通報者 / 対象（ユーザー or 発言 + リンク） / カテゴリ / 理由 / 件数集計 / 対応状況
- 通報詳細から運営アクションを実行可能に:
  - **入村制限**（指定ユーザーが新規に村へ入村できなくなる）
  - 通報の対応済みマーク
  - （後続検討）警告メッセージ送信、一時 BAN、発言削除

### 入村制限の仕様（最小）
- 管理者が対象ユーザーを「入村制限」状態にすると、全村への新規入村バリデーションで弾く
- 既に入村済みの村からの強制退村はスコープ外（要確認）
- 解除も同画面から可能

### 既存「突然死による自動入村制限」の削除
- 突然死回数をトリガーに自動で入村制限がかかる既存ロジックを **削除**
- 既存の入村制限カラム / テーブルがあれば、本 Issue で導入する管理者起因の入村制限と同じ仕組みに統合（別物にしない）
  - 仕組みを統合する場合、既存データの扱い（既に自動制限中のユーザーをどうするか）は要確認
- 突然死カウント自体を残すか削除するかは別議論（残しても無害なので一旦保持。ロジックだけ外す方向で要確認）

## スコープ・注意

- スコープ外: メール / Slack 連携、自動 BAN、AI による内容判定、通報のユーザー間公開
- 突然死による自動入村制限の削除は本 Issue に含める（運営の手動判断に一本化する方針）
- 認可: 管理者ロールの判定方法は既存のものを再利用（無ければ別 Issue 立てる必要あり、要確認）
- プライバシー: 通報内容は管理者のみ閲覧。通報者の身元は被通報者には開示しない
- 悪用対策: 同一ユーザーが連投通報できないよう件数制限を設ける
- 「入村制限」は #8 のユーザー個別ブロックとは別レイヤー（運営による全体制限 vs 私的制限）

## 影響範囲

- backend:
  - DB: 通報テーブル新規（`report`: id, reporter_id, target_type, target_id, category, reason, status, created_at 等）
  - DB: 入村制限テーブル / カラム（`user.is_village_restricted` or 別テーブル、要設計）
  - API: 通報作成 / 通報一覧（管理者）/ 通報ステータス更新 / 入村制限の付与・解除
  - 入村バリデーション: 「対象ユーザーが入村制限されていないか」を追加
  - 認可: 管理者ロールチェック
  - **既存の突然死起因の自動入村制限ロジックを削除**（突然死カウントを参照して入村制限を発動している箇所を特定して撤去）
- frontend:
  - 通報ボタン（ユーザープロフィール / 発言メニュー）
  - 通報モーダル（カテゴリ + 理由）
  - 管理者向け通報一覧ページ（新規ルート、認可ガード）
  - 管理者アクション UI（入村制限の付与・解除）

## 動作確認

- backend: lint / build / 単体テスト（通報作成、閾値超過判定、入村制限バリデーション）
- frontend: lint / build
- 手動確認:
  - [ ] 一般ユーザーが他ユーザー / 発言を通報できる
  - [ ] 同一対象への重複通報が制限される
  - [ ] 閾値超過で管理者ページに通知バッジが出る
  - [ ] 一般ユーザーが通報一覧ページにアクセスすると 403 / リダイレクト
  - [ ] 管理者が通報一覧から入村制限を付与すると対象ユーザーの新規入村が弾かれる
  - [ ] 入村制限を解除すると再度入村できる
  - [ ] 突然死を重ねたユーザーが自動で入村制限されない（既存ロジックが削除されていること）

## release-note

- 通報機能を追加。問題のあるユーザーや発言を運営に報告できます。管理者には専用の通報一覧ページから対応や入村制限の付与が可能になります。
- 突然死回数を理由とした自動入村制限は廃止し、運営による手動判断に変更します。
